# 双参考点折线动态绕障：独立离线实验

**结论：折线能使现有 DWA 主动向后侧横移，但本轮没有形成比停车等待更早的完整后绕。E 组出现制动后备禁行准入失效，立即停止全部后续模拟；不修复、不调参、不重跑。没有合格最优/次优方案，不进入真实 Controller 开发。**

## 决定性发现

1. **主动侧移已形成，但路线收益为负。** A/C 在6.20 s开始持续5cm后移，8.8前最大后移66cm；B/D在7.05 s达到持续5cm，最大44cm。这不是等待中的影子候选或入口前原地转向，而是实际位姿变化。但实际入区9.95/10.00/10.60/10.60 s，均晚于历史约8.8 s释放；完整通过14.25/14.35/15.10/15.15 s，也均慢于A0的14.05 s，更慢于B0的12.90 s。

2. **几何连通不保证有时间优势。** 固定后侧入口要求先完成较大横移，再转入水平段。原DWA可以执行这条偏离路线，但多走的距离和转向代价抵消了提前启动。H从1倍到2倍没有改善通过；4倍则推动E接近保守制动边界。不能由此推断8倍更好，停止条件已触发。

3. **释放折线不等于完整恢复。** A–D 在12.6 s通过原风险事件4秒有效空闲兜底释放、且普通安全候选支持向原路径靠近，取消折线。不是提前修改风险释放，也不是障碍物已被实际绕过。至16 s机器人仍偏离原路径约0.47–0.55 m，恢复仍在进行，不能宣称稳定完成导航。末端单测没有追点方向反转，A–D执行也无末尾纯转向，但因本次提前风险释放，没有完整实测逼近折线终点的所有行为。

4. **E的失效是安全条件，不能豁免。** 在7.15 s，位姿约 `(1.062027,-0.255189,-1.411425)`，速度 `(0.26,-0.662715)`；当时禁行纵向范围[1.08,2.12]、后边界-0.37m，50ms采样储备0.013m。因此保守纵向入口为1.067m。原名义零指令制动后备最大x=1.067119728，越界约0.0001197m；队列制动最大x=1.066951675，仍在边界之前。静态检查通过，两套真值制动近似净距均约12.65cm。由此能确定**名义制动禁行检查失败**；无需推测为碰撞，也不应视为可忽略误差。滚动工具在下一动作执行前撤销许可、输出停车并中止，未继续物理仿真来证明停车过程绝对安全。

A–D执行未记录接触、禁行区侵入或后备失效；E中止前也未记录执行接触/侵入，但出现1次后备失效，不能归类全程安全通过。所有额外参考余量仅用于折线设计，最小执行净距8.2–11.4cm说明它们不是0.1/0.2m硬净距保证。

## 筛选与证据

无合格首选或备选。仅作失败方案内部比较：A（1倍/0.1m）通过最快、仍慢于A0约0.20s，且净距8.26cm；B（1倍/0.2m）几何更保守、净距11.24cm，但通过慢1.05s。C/D加倍无收益；E安全淘汰；F/G/H因停止规则没有证据，不能排名。

41项单元/组件测试通过：既有31项＋10项折线测试，覆盖全连接段阻挡（端点仍安全）、坐标、窄通道、四帧/时间戳、锁定、反向/失联/后备、释放和末端切向。原失败测试与最终XML、完整原始轨迹/评分/输入/命令、实际ELF与动态插件/静态库SHA、代码提交及保护哈希均保存。安全硬筛选与执行代码块逐字保持。

分层结论：**离线几何通道存在；条件模型能主动向后侧移动并在A–D最终通过，但不比停车更早，也未在窗口内完成原路径恢复；E暴露后备可持续准入问题；真实ROS/Gazebo感知闭环尚未验证。** 本轮使用完整场景包络、理想关联/方向、当前位姿合成射线和未来真值门禁，不是历史Scan重放。不得将几何或单次无接触当成真实安全。
